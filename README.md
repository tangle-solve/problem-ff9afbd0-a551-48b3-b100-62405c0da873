- **Subfield:** Algebraic complexity and polynomial identity testing
- **Open:** Prove \(\omega=2\): for every \(\varepsilon>0\), multiply two \(n\times n\) matrices using \(O(n^{2+\varepsilon})\) arithmetic operations.
